监听范围
绑定所有网卡，局域网内任意地址都能连上。勾选后下面的本机 IP 列表不再参与监听。
本机 IP 地址
只监听勾选的地址（插件为每个地址建立一条 TCP 直通监听）；默认全不勾选 = 仅本机可访问。
端口
默认 3080。带 --port 启动时以命令行为准，此处不可编辑。
鉴权
勾选后，输入正确的 IP 与端口即可直接访问；Host/Origin 来源校验仍然保留。
「重启 dsh」会在后台按原命令重新拉起一个新实例，日志写到 ~/.dsh/logs/。绑定地址与端口保存后热重载即时生效。
本页说明：全局监听让所有网卡都可访问；本机 IP 列表用于把监听收敛到指定网卡；端口决定对外服务端口；取消鉴权会去掉 token 校验。
